# Функции, простые числа и модель охлаждения

![Стек](https://img.shields.io/badge/C%2B%2B-334155?style=flat-square) ![Семестр](https://img.shields.io/badge/семестр-2-0f766e?style=flat-square) ![Статус](https://img.shields.io/badge/статус-%D0%A3%D1%87%D0%B5%D0%B1%D0%BD%D1%8B%D0%B9%20%D0%BF%D1%80%D0%BE%D0%B5%D0%BA%D1%82-64748b?style=flat-square)

Лабораторная №3 восстановлена из локальных материалов. Три группы заданий: табулирование функции, проверка простоты чисел и исследование охлаждения кофе.

## Содержание

| Каталог | Что исследуется |
|---|---|
| [1zad](1zad/) | Кусочная функция и таблица её значений |
| [2zad](2zad/) | Генерация и проверка простых чисел, тесты Миллера, Поклингтона и ГОСТ |
| [3zad](3zad/) | Закон охлаждения, линейная аппроксимация и корреляция |

## Сборка и запуск

Файлы с `main()` — самостоятельные программы; их не нужно собирать в один исполняемый файл.

```bash
c++ -std=c++17 1zad/1.cpp -o function_table
./function_table

c++ -std=c++17 2zad/Tests.cpp -o prime_tests
./prime_tests

c++ -std=c++17 3zad/3.cpp -o cooling
./cooling
```
